# PyNexus — APK recovery build

هذا المستودع يعيد بناء التطبيق من ملف `base.apk` الذي سلّمه مالك المشروع. لم يتوفر مشروع Android/Gradle الأصلي، لذلك ملفات `overlay/` هي تعديلات على smali والموارد المفككة، وليست الشيفرة المصدرية الأصلية.

## ما يعمل في هذه النسخة

- توليد رمز API تلقائياً عند أول تشغيل بواسطة `SecureRandom` بالصيغة `py-` ثم 48 حرفاً سداسياً.
- زر لتشغيل API وإطفائه؛ يكون متوقفاً أول مرة. تدوير الرمز يبطل القديم فوراً.
- استقبال الرمز في ترويسة `Authorization: Bearer <token>`؛ إزالة كلمة المرور الافتراضية `admin123`، وإزالة وضع الرمز في عنوان URL، وإلغاء CORS المفتوح.
- تقييد مسارات API بملفات Python المسجلة ضمن مجلد التطبيق، ورفض أسماء الملفات غير الآمنة عند الرفع والاستيراد.
- تعطيل `debuggable` ونسخ البيانات الاحتياطية، ورفع رقم الإصدار إلى 6.

يستخدم API بروتوكول HTTP على المنفذ 8080 عند تشغيله. استخدمه على شبكة موثوقة فقط. يعرض التطبيق الرمز على لوحة التحكم. لم يجر اختبار تشغيل فعلي على جهاز أندرويد أو محاكي.

## البناء والفحص

تشغّل GitHub Actions ملف `scripts/build.sh` بعد كل دفع إلى `main`. أجزاء `vendor/base.apk.part*` تحفظ نسخة APK الأصلية كاملة، ويتحقق السكربت من SHA-256 قبل فكها. يحتاج البناء إلى Python 3 وJava و`apktool` و`aapt2` و`zipalign` و`apksigner`.

```bash
bash scripts/build.sh
```

يخرج `build/PyNexus-signed.apk` ويتحقق من توقيعه وسلامة ZIP وبيانات الحزمة. مع غياب أسرار التوقيع، ينشئ CI مفتاحاً مؤقتاً جديداً في كل تشغيل، ويكون الناتج للتجربة فقط. للحصول على توقيع ثابت، أضف إلى أسرار المستودع:

- `PYNEXUS_KEYSTORE_B64`: ترميز base64 الكامل لمفتاح PKCS#12 الخاص، بالاسم المستعار `pynexus`.
- `PYNEXUS_STORE_PASSWORD`: كلمة مرور المفتاح؛ استخدم القيمة نفسها لكلمة مرور المخزن والمفتاح.

**لا ترفع المفتاح أو كلمة المرور إلى المستودع العام.** التوقيع الجديد مختلف عن توقيع APK الأصلي، لذا لا يمكن تحديث تثبيت النسخة الأصلية مباشرة دون مفتاحها الأصلي. انسخ بياناتك أولاً، ثم أزل النسخة القديمة إذا أردت تثبيت النسخة الموقعة الجديدة.

## حدود الدعم الحالية

| الطلب | الحالة |
| --- | --- |
| تشغيل سكربتات Python | موروث من APK الأصلي؛ أعيد البناء، ولا يوجد اختبار جهاز |
| Pillow ومكتبات C | تحتاج عجلات Android مطابقة لـ Python 3.10 وABI واعتمادياتها الأصلية، مع دمجها في مشروع Chaquopy الأصلي؛ التثبيت من مصدر C على الهاتف غير مضمون |
| RDKit | لم تُثبت أو تُختبر عجلة Android مناسبة؛ يحتاج بناء NDK واعتماديات أصلية لكل ABI |
| سكربتات Java وبوتات Telegram | لا يوجد مترجم Java أو خط أنابيب DEX وتحميل اعتماديات آمن في APK الأصلي؛ لم تُضف هذه الميزة في إعادة البناء |
| النشر في Google Play | `targetSdkVersion=34` من APK الأصلي، لذلك يحتاج إعادة بناء من المصدر الأصلي بإصدار SDK مدعوم واختبارات جهاز |

لا ينبغي تقديم APK المعاد بناؤه على أنه إصدار إنتاجي شامل قبل استعادة مشروع Gradle الأصلي، إضافة الدعم الأصلي للمكتبات، واختبارات جهاز وأمان وظيفية.
